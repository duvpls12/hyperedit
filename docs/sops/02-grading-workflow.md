# SOP 02 — Grading Workflow

## FPS Policy for QA Analysis
- **Quick precheck:** 1 FPS (fast structural sanity only).
- **Baseline style analysis (default):** 5 FPS (required for motion/pacing/transition profiling).
- **Escalation analysis:** 8 FPS only when drift remains high after Cycle 2.
- For style recreation against a final deliverable, 5 FPS is the default gate input unless explicitly overridden.

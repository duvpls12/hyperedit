# Context - Footage Intake and Sorting

## Source patterns from tutorials

- Pre sorting by bins (wide, detail, drone, POV) speeds assembly.
- Directional continuity is non negotiable for smooth flow.
- Wide/detail alternation prevents visual fatigue.
- Straight push shots can reset directional flow before switching side.
- Stabilization viability should be assessed before committing clips.

## Sequence heuristics

- Start with teaser details before full reveal for suspense.
- For MLS clarity, prioritize spatial orientation and room coverage.
- For cinematic reels, prioritize movement rhythm and emotional momentum.
- Preserve key selling features early (view, pool, architecture, lifestyle anchor).

## Gap handling logic

From `Editing/Editing.md` and walkthrough behavior:

- Prefer real adjacent footage before generation.
- Keep room block integrity; do not steal clips that break future required reveals.
- If missing detail shot in critical block, synthetic insert is allowed with strict realism QC.

## Common failure modes

- Over selecting similar shots with redundant motion.
- Ignoring micro jitter that later breaks speed ramping.
- Missing sequence bridge shots that cause hard narrative jumps.

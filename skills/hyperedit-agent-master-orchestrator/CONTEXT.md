# Context - Master Orchestrator

## Source patterns from tutorials

- Simplicity and repeatability outperform over complex edits.
- Song selection and structure are upstream decisions, not finishing tasks.
- Directional flow consistency is a core continuity rule.
- Workflow pass order reduces wasted work: story/build/refine then finishing passes.
- Hook alone is insufficient; periodic rehooks maintain watch time.

## Core planning heuristics

- Sequence by dependency, not by editor preference.
- Keep synthetic generation constrained to gaps with high narrative impact.
- Delay expensive processing (heavy denoise/sharpen) until late stage.
- Preserve project type behavior:
  - MLS: clarity and room coverage first.
  - Signature/viral: tension cycles and creative peaks first.
  - Family friendly: approachable pacing and warm tone.

## Failure patterns to watch

- Color done before edit lock leading to rework.
- Direction reversals causing jarring cuts.
- Excessive effects that distract from property value.
- Audio effects overpowering music or dialogue.
- Caption styling that blocks subject faces or property details.

## Decision matrix for synthetic generation

- Use generation only when a coverage gap blocks story flow.
- Prefer borrowing adjacent usable shots before generating new footage.
- Reject synthetic inserts if visual realism fails QC.

## Completion definition

Project is complete when all stage artifacts are `pass` or accepted `warn` with no blocking issues.

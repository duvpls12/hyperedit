# Context - Color Pipeline

## Source patterns from tutorials

- Main error to avoid: applying creative LUT too early.
- Correct order: conversion -> base correction -> contrast shaping -> creative look.
- Use adjustment layers to keep grade organized and global controls simple.
- Use waveform to keep highlight/shadow integrity.
- Match white balance to avoid amateur "clip to clip" jumps.

## Practical grading heuristics

- Drone footage often needs selective exposure balancing.
- Interior window scenes need highlight control with midtone lift.
- Keep skin tones believable even with stylized looks.
- For social outputs, prioritize clean contrast and immediate readability on mobile.

## Advanced but optional techniques

- Luma key based window isolation.
- Subject masking for talent centered reels.
- Halation or glow only when it supports mood and does not look synthetic.

## Failure modes

- Over saturation and crushed dynamic range.
- Inconsistent tint shifts between shots.
- Heavy processing before final cut causing wasted render time.

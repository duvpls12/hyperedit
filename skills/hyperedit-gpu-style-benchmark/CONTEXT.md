# Context - Style Benchmark

## Core idea

You do not need raw footage to benchmark editing style. Final cuts encode the editorial strategy.

## Benchmark value

- Identifies what to repeat versus what to avoid.
- Lets orchestrator choose strategy by property type and platform.
- Produces measurable defaults for new edits.

## Risks

- Weak benchmark quality when sample set is too small.
- Misleading conclusions if labels are inconsistent across videos.
- Overfitting to one editor's aesthetic.

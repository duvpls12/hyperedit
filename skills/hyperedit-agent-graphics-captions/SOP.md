# SOP - On Screen Graphics and Captions

## Objective

Increase comprehension and retention using captions and graphics that support the story without obstructing visuals.

## Inputs

- Picture locked timeline.
- Dialogue transcript.
- Brand style constraints.

## Procedure

1. Create caption transcript with phrase level timing.
2. Select caption style by project type:
- Family friendly MLS: clean and simple.
- Signature reel: expressive but restrained.
3. Apply captions line by line with timing first, then positioning pass.
4. Keep key subject areas visible; position text to retain face and feature visibility.
5. Add motion tracked text only where it adds narrative value.
6. For 3D tracked titles, validate depth and occlusion realism.
7. Add supporting graphics (price, location, feature callouts) with consistent hierarchy.
8. Run mobile viewport QC for safe margins and readability.

## Quality gates

- No caption collisions with faces or key property details.
- Typography remains consistent and legible at phone viewing size.
- Motion graphics are subtle and purpose driven.
- Any tracked text remains locked to scene motion.

## Outputs

- `50_caption_script.json`
- `51_graphics_layout.json`
- `52_graphics_qc.json`

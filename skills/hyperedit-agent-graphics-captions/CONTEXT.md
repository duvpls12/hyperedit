# Context - Graphics and Captions

## Source patterns from tutorials

- Captions are often done late and can be the most time intensive pass.
- Effective approach: timing pass first, layout/style pass second.
- "Simple and classy" caption styling performs reliably.
- Text placement should preserve viewer focus on subject and property.
- Motion tracked text and 3D titles are high impact, but overuse hurts clarity.

## Caption heuristics

- Break lines by phrase and emphasis, not strict word count.
- Use contrast against local background and adapt placement per shot.
- Keep tracking/kerning and line spacing consistent across reel.
- Fade and entry animation should match pace of the cut, not distract from it.

## Graphics heuristics

- Promote only one key message at a time.
- Use feature callouts where the visual supports the claim immediately.
- Reserve complex effects for hook or major reveal moments.

## Failure modes

- Template heavy captions that ignore shot composition.
- Over animated text that competes with footage.
- Inconsistent font/weight/case patterns across scenes.

## Shot Grammar Rules

### Pacing
- **~78 shots per video, avg 1.49s/shot** — this is fast. Social/reel-style cutting.
- **Cinematic real estate ≠ slow luxury pacing** — the corpus shows rapid-cut editorial.
- A 90s property video has ~60 cuts. A 2-min video has ~80 cuts.

### Shot Type Hierarchy
```
1. pan / wide_establishing  ≈ 35%  — establishing and space-reading shots
2. exterior               ≈ 11%  — curb appeal, arrival
3. wide                   ≈  9%  — room intros
4. static                 ≈  9%  — detail holds
5. interior               ≈  7%  — room flow shots
6. aerial_oblique         ≈  6%  — property-in-context
7. aerial (overhead)      ≈  5%  — neighborhood/lot overview
8. panoramic              ≈  4%  — 180° reveals
9. medium                 ≈  3%  — lifestyle / human scale
10. title card             ≈  2%  — text overlays / address cards
```

### Composition Hierarchy
```
1. wide                ≈ 19%  — standard room reading
2. landscape           ≈ 13%  — horizontal-dominant framing
3. symmetrical         ≈ 13%  — architectural grammar
4. depth_layering      ≈  8%  — foreground / background separation
5. rule_of_thirds      ≈  8%  — standard cinematic
6. centered / framing  ≈  7%  — hero focus
7. symmetry            ≈  5%  — doorways, corridors, pools
8. panoramic           ≈  4%  — wide horizontal
```

### Sequence Role Pattern
```
Intro / hook:         ≈ 51%  (introductory + intro_hook + intro)
Room showcase:        ≈ 15%  (room_showcase)
Background context:   ≈  7%  (background)
Overview / establish: ≈ 11%  (overview + establishing shot + establishing)
Detail / close:       ≈  6%  (detail + detail shot + detail_moment)
```

### Typography Usage
- **9.8% of frames carry text overlays** (address, price, agent info, property name)
- Typography is clustered at the start (address card) and end (agent card)
- Mid-video text should be avoided — it breaks immersion

### Editorial Rules
1. Start with wide establishing or aerial — set location context in the first 3 seconds.
2. Interior flow: living room → kitchen → dining → bedroom → bathroom (loop back).
3. Use symmetrical / depth_layering compositions for architectural hero shots.
4. Rule-of-thirds for lifestyle and detail inserts.
5. Aerial oblique for mid-video location refresh, not just openers.
6. Title cards appear at start and end — never mid-flow.
7. Keep average shot duration ≤ 2s for social; ≤ 3s for YouTube long-form.
